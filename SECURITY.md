# Security Policy

This repository contains the public material knowledge-graph pipeline only.

Report vulnerabilities through the repository's GitHub Private Security Advisory. Do not open a public issue for credential exposure, unsafe graph mutation, provenance bypass, tenant leakage, or sensitive source-data disclosure.

Never include API keys, tokens, DSNs, passwords, private keys, NAS addresses, raw documents, complete parser output, vector archives, or database exports in reports. Revoke exposed credentials before sharing a redacted identifier.

Ordinary defects should include the affected commit, minimal synthetic reproduction, expected behavior, and relevant schema or generation identifiers.
